# Ranking de Universidades de Latinoamérica y España

Ranking **bibliométrico, abierto y reproducible** de ~1.000 universidades de la región (21 países), construido solo con datos abiertos (OpenAlex CC0 + SCImago).

**Live:** https://unimauro.github.io/universidades-latam/

Índice de impacto ponderado (anti-volumen inflado), calidad Q1-Q2, ranking por país, mapa, comparador. Más transparente que los rankings tradicionales: cada número es reproducible desde la API pública de OpenAlex.

Exploratorio e independiente, no oficial. Léase junto a Leiden Ranking Open y SCImago. Construido por Carlos Cárdenas (@unimauro).
